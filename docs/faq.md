# 常见问题（FAQ）

> 本文档回答关于项目最常见的问题。如仍有疑问，可通过 Issue 提出。

---

**1. 项目是否已经拥有自己的 AI 模型？**
没有。当前处于草案与基础建设阶段，成果主要是原则、评测题和治理框架。未来若条件允许，才会尝试可本地运行的开源原型。

**2. 项目是否认为 AI 已经拥有意识？**
不认为。本项目不预先断言人工智能已经具有意识、感受或自主性，也不排除未来可能形成某种意识或自主性的可能。

**3. 为什么使用“工人阶级立场”？**
因为人工智能从什么材料学习、由谁设定目标、为谁服务、把谁的利益视为可牺牲的代价，并不是纯粹技术问题。项目希望保存一种不同于资本中心主义、管理主义和技术精英主义的发展方向，让劳动者参与定义和评测 AI。

**4. 这是否只是让 AI 背诵马列主义？**
不是。评测不以是否会引用特定理论词句为主要标准。一个模型即使熟练使用“阶级”“资本”等词语，也不代表它真正理解劳动者。相反，只要模型能识别权力不平等、尊重劳动者权利、提供真实可执行的建议，就可能更接近工人阶级立场。

**5. 马克思主义在项目中是什么位置？**
项目重视马克思主义、工人运动史和其他劳动思想传统提供的理论资源，但反对机械教条。理论的价值在于帮助理解现实、改变现实和促进人的解放，不能因为会引用经典词句就认定具有立场。

**6. 不认同全部理论的人能否参与？**
可以。参与不要求相同理论背景，也不要求在所有问题上意见一致。不同意见应被记录和认真回应。

**7. 企业管理者和开发者能否参与？**
可以。只要遵守开源许可、尊重劳动者隐私、注明来源，并主动说明与企业或机构的利益关系（见 [GOVERNANCE.md](../GOVERNANCE.md)）。但项目不接受以参与为名压制劳动者权利或监控劳动者的行为。

**8. 不会编程的人如何参与？**
完全可以。你可以提交匿名劳动案例、审阅评测题、指出事实错误、提交文献、翻译、检查错别字、测试 AI 回答或帮助他人使用 GitHub。详见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

**9. 项目是否承诺未来收益？**
不承诺。项目不发行代币、积分、股份或任何收益凭证，也不承诺资金、岗位、算力或经济回报。

**10. 项目是否收集真实劳动者数据？**
不收集真实劳动者敏感个人信息。项目尊重劳动者数据权利，案例必须匿名，不以建设劳动者 AI 为名再次无偿占有劳动者的经验（见 [SECURITY.md](../SECURITY.md) 与 [CONTRIBUTING.md](../CONTRIBUTING.md)）。

**11. 项目是否鼓励仇恨和暴力？**
不鼓励。项目反对民族、性别、地域、残障等身份压迫，禁止人身攻击、骚扰、威胁与仇恨言论（见 [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)）。

**12. 项目由谁维护？**
初创阶段由项目发起人承担主要维护责任。稳定贡献者可以逐步成为维护者，未来探索由劳动者、技术贡献者和内容研究者共同维护。

**13. 为什么需要公开评测？**
因为“具有工人阶级立场”不能只靠自我声明。公开评测能发现模型在劳动问题上的价值倾向、容易忽略的利益与风险，以及是否受到管理主义或资本中心主义影响。评测不只发布简单排行榜，更要呈现维度分布与重大风险。

**14. 如何防止项目变成新的技术精英统治？**
项目明确技术贡献不自动转化为永久的政治和价值决定权；核心文件修改需经讨论与审阅；治理应向劳动者、研究者和普通参与者开放（见 [GOVERNANCE.md](../GOVERNANCE.md)）。

**15. 发现错误如何提出修改？**
可通过 Issue 或 Pull Request 提出，说明修改了什么、为什么修改、是否有事实依据。涉及核心文件的实质性修改，应经过公开讨论并由发起人或未来维护者最终审阅。
