# 贡献记录（contribution-records）

> 本文件是“贡献记录”的集中视图，与 [../CONTRIBUTORS.md](../CONTRIBUTORS.md) 配合使用。正式记录随真实贡献发生而补充。

---

## 记录原则

- 项目尊重并记录真实劳动；
- 贡献形式多样：代码、写作、翻译、案例、审阅、纠错、社区维护与组织；
- 不能只承认容易被软件统计的劳动，也不能把基础性、照护性和协调性工作变成不可见劳动；
- 贡献记录不代表经济权益、股份、代币或确定的未来收益；
- AI 可以协助整理贡献，但不能单独决定人的价值和资源分配。

## 如何被记录

- 通过 Pull Request 合并的贡献，由维护者按本框架登记；
- 不会使用 Git 的贡献者，可通过维护者公布的渠道提交，由维护者代为登记并注明；
- 是否公开身份由贡献者决定（真实姓名 / GitHub 用户名 / 化名 / 匿名）。
