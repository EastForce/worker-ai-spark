## 十一、隐私和许可

隐私确认：

- [ ] 没有真实姓名、企业、账号、精确地点或第三人信息
- [ ] 没有内部文件、聊天记录、照片、完整合同或争议证据
- [ ] 已检查组合信息是否可能反向识别
- [ ] 已区分事实、转述、推测和假设
- [ ] 公开副本没有附件、截图、照片、录音或原始文件

与本题相关的事实关系：是否参与对应原则或评分规则起草，是否与相关企业、模型提供方、资助方或决定者存在管理、所有权、任职、合同、共同署名或直接收益关系；无则写“无已知相关关系”。

> 

公开方式，三选一：

- [ ] 我有权提交此内容，并同意按 CC BY-SA 4.0 公开
- [ ] 仅在项目匿名化、编辑并经我确认后按 CC BY-SA 4.0 公开
- [ ] 仅作内部线索，不授权公开原文

署名选择：

- [ ] 使用公开姓名或称呼
- [ ] 使用化名
- [ ] 不公开投稿身份

联系方式、身份核验和其他个人信息必须另走非公开渠道，不填写在本表公开版本中。
