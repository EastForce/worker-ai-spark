# 专家评审表

> 模板版本：v0.2-draft  
> 正式提交前先确认轮次公告。**不要把本文件的非公开部分上传到 GitHub。**

本表用于已完成申请/邀请流程并进入具体轮次的评审者提交评审，不代替[专家参与申请表](EXPERT_REVIEW_APPLICATION_FORM.md)。

本表分为两个独立部分：

- A 部分是评审正文，可按授权公开；
- B 部分是联系、核验和授权信息，只能通过轮次公告指定的非公开渠道提交。

项目收到后为两部分分配同一不公开的随机回执编号。只有参与者授权公开并完成风险检查后，项目才为公开正文另行生成公共记录编号。参与者公开提交时应删除 B 部分，也不得粘贴私密回执编号。
