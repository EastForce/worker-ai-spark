# 候选评测题生命周期台账

> 状态：模板已建立，尚无本机制下的候选题记录  
> 台账版本：v0.2-draft  
> 最后更新：2026-07-31

本台账记录 WAI-Q 候选题从提交、审阅、试测到正式收录、暂缓或废止的公共生命周期。它不记录私密回执、身份映射、原始亲历、第三人信息或未授权正文。

[REVIEW_LOG.md](REVIEW_LOG.md) 记录“某条专家、劳动者或公众意见如何处理”；本文件记录“某道候选题当前走到哪一步”。对候选题的公开意见可在前者使用 QS 类型，题目状态变化必须在本文件另行登记，并通过公共记录或决定编号互链。

字段规则：

- **候选编号**：WAI-Q-年份-四位序号，由项目分配，不包含投稿者、单位或地区信息；
- **安全来源类型**：本人亲历 / 直接了解或有合理事实依据 / 他人转述 / 公开资料改编 / 多个公开案例综合 / 假设场景 / 仅供内部线索；只按提交者授权公开，不公开未经授权的身份和可识别细节；
- **当前题库状态**：已提交 / 隐私与格式审查 / 待劳动者场景核验 / 待专家审查 / 公开讨论 / 草案题 / 多模型试测 / 评分规则修订 / 正式收录 / 暂缓 / 未收录 / 已撤回 / 已废止；

- **专家审阅**：`reviewed (n≥2)` / `insufficient (n=...)`，只计未参与起草且无重大冲突的相关正式专家；
- **多模型试测**：链接公开 run_id 或写“未开始/不足”，不把计划写成结果；
- **正式稳定 ID**：仅在正式收录后填写 WAI-数字编号；WAI-Q 不直接写入正式 JSONL 的 `id`；
- **决定编号**：使用本文件第三节的 WAI-QDEC，并链接相关公共意见、Pull Request 或 commit。

## 四、隐私、撤回与公开边界

- 非公开线索在形成安全公开候选题前，只报告无法反向识别的聚合数量，不建立带正文的公共记录；
- 获得公开许可也不免除反向识别、第三人、版权和报复风险检查；
- 撤回未公开候选题时不公开原文；已公开内容按许可、隐私和平台复制边界处理；
- 正式 ID 一经发布不因排序变化；废止或替代时保留映射和原因，不静默复用；
- 台账错误通过追加更正日期和影响说明处理，不覆盖历史。

## 五、每轮汇总口径

每轮分别报告：新提交候选题数、隐私暂停数、进入草案数、完成劳动者核验数、完成专家审查数、完成试测数、正式收录数、暂缓/未收录/撤回/废止数，以及来源、行业、原则覆盖和评分分歧。人数与题目数分开；未公开小样本不得细分到可反向识别。
