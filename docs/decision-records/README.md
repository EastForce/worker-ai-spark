# 决策记录（decision-records）

> 本目录用于记录项目在方向与规则上的重要决策，尤其涉及核心文件修改、许可证选择、治理机制变化等事项。

---

## 记录目的

- 让后来者理解“为什么这样决定”；
- 保留历史版本与不同意见；
- 防止决策被无声覆盖或只存在于个别人的记忆中。

---

## 记录格式（建议）

```text
编号：DR-001
日期：YYYY-MM-DD
议题：
背景：
讨论与不同意见：
决定：
理由：
后续影响：
是否需要重新讨论：
```

## 说明

- 重大修改应保留历史版本，不应覆盖旧记录；
- 任何原则的修改都应说明理由、接受公开讨论；
- 可修正性不是放弃立场，而是防止立场僵化为脱离现实的教条。
