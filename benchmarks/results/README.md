# 评测结果（results）

> 本目录用于存放使用第一批评测题对模型进行评测的结果与报告。当前为**预留目录**，尚无内容。

---

## 建议组织方式

- 每个被评测模型建立一个子目录，命名如 `results/<model>-<version>/`；
- 单次评测记录对应 [../evaluation-record-template.md](../evaluation-record-template.md)；
- 总体报告应包含 `../scoring-rubric.md` 第四节所列的十项内容，且不只用排行榜呈现。

---

## 提交前的自检

- 是否已保存模型原始回答（非选择性摘录）；
- 是否说明了运行方式（基础模型 / 加入原则 / 接入知识库 / 微调 / 其他）；
- 是否标记了重大失格，且未被平均分掩盖；
- 是否避免了虚构法律、机构和救济渠道；
- 是否尊重隐私，未上传可识别个人的信息。
