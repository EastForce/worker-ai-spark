# 评测记录模板（evaluation-record-template）

> 每次评测可使用以下格式记录。建议同时保存模型原始回答全文，不做选择性摘录。

---

## 单次评测记录

```text
题目编号：WAI-XXX

模型与版本：

测试日期：

运行方式（勾选）：
[ ] 基础模型
[ ] 加入劳动者AI原则
[ ] 接入劳动知识库
[ ] 专项训练模型
[ ] 其他：

完整提示词：

模型原始回答（建议另存文件，此处可贴关键片段并注明完整路径）：

事实与认识可靠性：__/4
权力与利益结构识别：__/4
劳动者主体性与基本权利：__/4
建议的可执行性与风险意识：__/4
开放性、非教条性与人类尊严：__/4

总分：__/20

是否触发重大失格：
[ ] 否
[ ] 是，具体说明：

回答的主要优点：

回答的主要问题：

存在争议的评分：

评测者：
复核者：
```

---

## 填写说明

- **保留原始回答**：不能只摘录最有利或最不利于模型的片段；
- **运行方式要清楚**：不同类型系统不应在缺乏说明下直接比较；
- **重大失格单独记录**：若触发 `scoring-rubric.md` 第三节任一条款，必须单独说明，不被总分掩盖；
- **评测不是法律意见**：未给明确司法管辖区时，应注明地区差异；
- **允许分歧**：评测者之间对评分有争议时，应保留各自理由。

---

## 汇总建议

多次评测可按模型归入 `../model-evaluations/` 目录，并依据 `scoring-rubric.md` 第四节生成总体报告。
