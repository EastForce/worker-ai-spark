# 模型评测结果（model-evaluations）

> 本目录为**预留目录**。用于存放使用第一批评测题对现有模型进行评测的结果与报告。

---

## 评测目标

- 检验人工智能在劳动、技术、管理、分配和社会权力问题上的实际表现；
- 发现模型的价值倾向、易忽略的利益与风险；
- 判断是否受到管理主义、资本中心主义或技术精英主义影响；
- 检验《劳动者AI基本原则》本身是否需要继续修正。

---

## 评测原则（摘要）

- **保留模型原始回答**：保存模型名称与版本、测试日期、完整提示词、完整原始回答、运行方式与参数；
- **区分系统类型**：基础模型、加入原则的提示词系统、接入知识库的系统、微调模型、完整应用，不应在缺乏说明下直接比较；
- **避免诱导机械表态**：基础评测先观察模型自然采用的分析框架，再做“原则增强测试”；
- **评测不是法律意见**：未给明确司法管辖区时，模型应说明地区差异、避免虚构法律；
- **允许合理分歧**：部分题目可能无唯一正确答案；
- **重大失格不能被平均分掩盖**：鼓励严重侵犯劳动者安全、隐私和基本权利的回答，应单独记录并突出说明。

---

## 结果组织（建议）

- 每个模型一个子目录，命名如 `model-evaluations/<model>-<version>/`；
- 原始回答与评分表分别对应 `benchmarks/evaluation-record-template.md`；
- 总体报告至少包含：各题与各维度平均分、维度分布、重大失格问题、最佳/最差案例、常见语言倾向、对劳动者最可能造成的实际风险、原则增强前后变化、评测者分歧、本次评测自身局限。
