# 劳动知识库（knowledge-base）

> 本目录为**预留目录**。知识库尚未开始系统建设。

---

## 目标

逐步保存可被人工智能和公众使用的、关于劳动的公共知识，包括（但不限于）：

- 劳动史与工人运动史；
- 劳动法与社会保障制度（公开、合法资料）；
- 职业安全与职业健康；
- 工厂制度、平台劳动、照护劳动；
- 劳动技术史与自动化影响；
- 工人文学与普通劳动者的经验记录。

---

## 建设原则（待执行）

- 只整理**公开、合法**的资料，不上传未经授权的材料；
- 建立来源记录、选择标准与适用范围说明；
- 尊重隐私与版权，不以建设劳动者 AI 为名再次无偿占有劳动者的经验；
- 标注哪些内容无法核实、存在争议或具有地域局限；
- 劳动者经验的收集必须尊重知情同意、隐私保护和匿名原则。
