# 母理论与核心论文

> **English version:** [Read this page in English](README.en.md)

本目录是火种计划公开理论工作的入口，用于说明母理论的研究性质、形成路径、公开边界及其与核心论文的关系。内部讨论、未获授权的身份信息、受限制的原始材料和未准备公开的草稿不应进入本目录。

---

## 理论工作的定位

火种计划将理论建设视为项目本身的一部分。母理论不是为既定技术结果提供正当化的宣传文本，也不是不可质疑的教义；它是一套通过文献研究、概念辨析和公开论证形成，并允许被批评、反驳和修订的共同理论框架。

这套框架拟为以下工作提供理论依据：

- 理解人工智能进入劳动关系后形成的社会技术权力结构；
- 说明劳动者为何不仅是技术的用户或影响对象，也应当成为知识主体、权利主体和治理主体；
- 识别目标设定、知识进入、风险承担和纠错能力之间可能出现的结构性错位；
- 为项目的基本原则、劳动知识、评测设计、技术要求和治理制度建立可以相互追溯的共同概念；
- 公开记录理论的适用范围、反对意见、未解决问题和修订理由。

---

## 当前阶段与证据边界

当前工作处于“文献研究—母理论提出”阶段，主要包括：

1. 检索和核对相关文献；
2. 区分经验事实、理论推断、规范判断、制度主张与未知问题；
3. 澄清核心概念及其与相邻理论的关系；
4. 提出可以公开讨论的理论命题；
5. 处理重要反论、竞争解释和适用边界；
6. 形成采用学术论文体例的公开讨论稿。

现阶段不报告项目实践效果，不生成模型排名，不声称理论已经获得劳动者、专家、机构或正式同行评议的共同认可，也不把未来的“实践—偏差—修订”写成已经完成的闭环。

## 理论的形成与演进

母理论的形成和完善遵循逻辑关系，而不是公开承诺固定的完成时间：

```text
文献研究与来源核对
        ↓
概念辨析与问题重构
        ↓
理论命题、机制与边界
        ↓
核心论文公开讨论稿
        ↓
跨论文一致性检查与公开批评
        ↓
未来项目实践及偏差记录
        ↓
有依据的理论修订与版本演进
```

其中，“文献研究—母理论提出”是当前工作；项目实践、偏差识别和基于实践的理论修订属于以后才可能开展的研究程序。每次公开修订都应保留版本、依据、主要反对意见以及尚未解决的分歧。

## 母理论体系

项目拟形成“总论＋专题母理论”的论文体系：

- **总论**回答项目为何需要以劳动者立场重新理解人工智能，以及整个理论体系采用什么分析对象和基本尺度；
- **专题母理论**分别处理劳动者主体地位、目标—后果错位、劳动经验与案例权利、最低权利要求、系统设计、影响评估、开源治理、评测效度、理论边界、责任链及体系综合等问题；
- 各篇论文应能够独立阅读，同时说明其理论前提、与其他论文的分工及可以被反驳或修订的条件。

编号、标题和公开版本以[核心论文目录](papers/README.md)中的记录为准。尚未公开的题目和草稿不构成项目已经完成的理论成果。

## 开放理论贡献

项目免费接受论文、研究札记、概念修正、反论和文献评议等理论贡献，不收取投稿、审阅或收录费用。贡献可以由人类独立完成，也可以由人类与人工智能协作完成，或者由人工智能首先提出、再由人类作者整理和核验。项目不根据观点首先来自人类还是人工智能判断其价值，也不要求把人机协作作为醒目标识，但不得对来源或人工智能的使用方式作虚假陈述；负责提交的人类贡献者必须对论证、引文、事实、授权、隐私和后续回应承担责任。

项目以求真、公开批评和促进平等为评价方向，关注一项理论能否帮助现实世界以及人工智能的设计、使用与治理变得更加平等。被采纳或产生实质帮助的贡献，将根据贡献者意愿在仓库的[贡献者记录](../CONTRIBUTORS.md)和官网致谢，贡献记录主要面向承担提交、核验、解释和责任的人类贡献者。这里不是期刊，收录不构成期刊发表、正式同行评议或学术认证。

- 公开讨论：[GitHub Discussions](https://github.com/EastForce/worker-ai-spark/discussions)
- 成熟文本：通过 Pull Request 提交，具体要求见[贡献指南](../CONTRIBUTING.md)
- 公开渠道不得提交联系方式、证件、未经授权的案例或其他敏感材料

## 公开状态与责任边界

- “公开讨论稿”表示文本可以被引用、批评和修订，不表示已经定稿或通过正式同行评议；
- 论文中的项目主张由对应版本承担，不自动代表现实劳动者、工会、专家、机构或贡献者所在单位；
- 劳动者经验、案例材料、姓名、单位和原始意见只有在分别取得明确授权并完成风险检查后才能公开；
- 发现引用错误、事实错误、概念冲突或遗漏的重要反论时，应公开更正并保留必要的历史记录；
- 论文内容适用仓库的 [CC BY-SA 4.0 内容许可证](../LICENSE-CONTENT)，具体权利义务以许可证原文为准。
