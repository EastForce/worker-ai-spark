## 论文定位

本文是火种计划专题母理论的第一篇，讨论劳动者为何不能只被视为人工智能治理的对象、数据来源或一般利益相关者，而应具有具体部署中的治理主体资格。

论文将这一资格重构为权利、能力、发言与救济四项制度功能，分别回应地位被交易、形式资格无法行动、规则单方形成和错误无法纠正。四项功能是一个可被合并、扩展或收缩的候选规范与诊断框架，不是跨法域的穷尽权利清单。

仓库版本以现有 Word 论文为底稿，保留了原有论证密度、表1、14条来源脚注和学术论文体例，主要作了以下重构：

- 将“权利—能力—发言—救济”明确为四项制度功能，而非跨法域现行义务的完备清单；
- 保留正当管理、真实同意、外部监管、内部多数与所有权吸收等最强反论，增强分类的可反驳性；
- 增加对火种计划的理论约束，但不把未来应建立的权利、参与和纠错机制写成当前成果；
- 明确与后续权利束、案例授权、影响评估、开源治理、评测效度和责任理论的分工边界；

## 已知局限、重要反论与待解决问题

- 当前文献基础不是按预先注册协议完成的穷尽性系统综述，遗漏文献可能改变分类和边界判断。
- “有效权利”、“民主问责”或单一的非支配原则，可能以更少的概念承担同样任务；若不损失诊断信息，四分法应当合并。
- 真实同意、低依赖退出或强前置公共规制，可能在部分场景中降低劳动者直接发言的必要性；其适用条件仍需进一步比较。
- 四项功能尚未形成通过内容效度、判定一致性和跨群体等值性检验的测量工具，也尚未经过项目实践检验。
- 即使四项功能完整实现，所有权、收益分配、劳动时间和集体力量仍可能造成结构性支配。
