## 总论功能

本文是火种计划母理论体系的总论起点。它不把“以人为本”理解为模型语言中的一般善意，而是把研究对象确定为人工智能进入劳动关系后形成的社会技术权力链，并集中回答三个问题：谁有权定义技术目标，谁承担系统错误和技术转型的代价，谁拥有纠正系统的现实能力。

论文提出“目标—后果错位”这一中层概念，以连接生产关系、目标编码、知识可见性、后果分配和制度纠错；从劳动过程知识、风险承担和共同生产者的政治资格说明劳动者立场的根据；并将“权力敏感对齐”限定为目标正当化、行为约束和纠错权配置构成的最低治理结构。该结构不是劳动者解放的充分条件，也不能替代所有制、收益分配、劳动时间和集体力量的改变。

## 已知局限与欢迎讨论的问题

- “目标—后果错位”的四项近端机制尚需在不同所有、治理和劳动情境中比较检验；
- 当前文献基础不是穷尽性的系统综述，遗漏文献可能改变创新性与边界判断；
- 从资本主义机器应用批判转向社会主义市场经济中的制度分析，仍需要更具体的公共所有、工会、集体协商和公共服务研究；
- “劳动者”同无酬照护者、经济依赖型自雇、失业者、基层管理者之间的概念边界仍可进一步细化；
- 公开、参与、评测与现实权力转移之间的关系，需要后续专题论文分别论证。
