# 火种计划——开源劳动者AI

> 火种计划是一个尝试为未来人工智能保存劳动者立场、劳动知识、公开评测和共同治理机制的开源项目。

[中文项目名] 火种计划——开源劳动者AI

[仓库名] `worker-ai-spark`
[当前阶段] 首发草案建设（v0.1）；评审机制筹备中

## 为什么需要这个项目

人工智能正在进入招聘、考核、排班、生产管理、公共服务和社会决策。无论未来人工智能是否真正产生意识，随着其知识结构、推理能力和行动能力不断增长，它所具有的价值倾向和社会立场都会产生现实影响。

本项目基于以下判断：

- **人工智能并非天然中立。** 它由特定的数据、目标、制度和权力关系塑造。
- **劳动者不能只成为被管理和被替代的对象。** 当人工智能把裁员称为“组织优化”、把延长工时称为“提高人效”、把全面监控称为“精细化管理”时，它使用的并不是完全中立的语言。
- **劳动者应当参与定义和评测人工智能。** 那些建设工厂、维护机器、编写程序、运输货物、照护病人、清洁城市、耕种土地、教育儿童的人，应当成为人工智能的共同塑造者，而不只是它的用户和数据来源。

本项目希望为人工智能保存一种不同于单纯资本中心主义、管理主义和技术精英主义的发展方向。

## 当前项目状态

请先看清项目的边界：

- 当前处于**草案和基础建设阶段**；
- **尚未训练专属模型**；
- **尚未证明人工智能已经产生意识**；
- 当前成果主要是**原则、评测题和治理框架**；
- 未来若条件允许，才会尝试建设可本地运行的开源原型。

我们不声称已经拥有一个真正具备工人阶级意识的人工智能，也不以短期内训练出最强大的模型为目标。我们首先希望保存一颗火种。

## 如何参与

本项目特别希望那些通常只能被人工智能系统分析、考核和管理的人，也能参与定义人工智能。参与**不要求会编程**。

你可以：

- **提交劳动情境**：可以提供本人亲历、直接了解或有合理事实依据的真实案例，也可以提交公开来源、综合场景或假设场景；可以选择实名、化名、匿名或仅供内部处理，身份与案例的公开范围分别授权。GitHub 账号始终可见，匿名或仅内部提交须使用后续公布的非公开渠道；
- **审阅评测题**：判断题目是否符合现实、是否遗漏；
- **指出事实错误**：发现错误引用、失效链接或法律适用性问题时提出；
- **提交文献**：补充公开、合法的劳动研究资料与来源；
- **参与翻译**：帮助项目触达更多语言人群；
- **编写代码**：数据格式、评测脚本、本地模型运行、网页展示、自动化测试；
- **测试模型**：用评测题检验现有模型的回答；
- **改善治理**：帮助完善贡献、修订与争议处理机制；
- **审阅基本原则**：可从专业研究或真实劳动经验提出逐条意见；
- **通过 Issue 参与**：不会使用 Git 也可以，详见 [CONTRIBUTING.md](CONTRIBUTING.md)。
